# PonyPen Game 

This is a clone of the [enclose.horse](https://enclose.horse/) game built 100% with AI coding agents.
The purpose was to test:
- SDD (Specification-Driven Development): 
  See the [spec/](spec/) dir.
- BDD (Behavior-Driven Development): 
  Behavior is specified in `.feature` [Gherkin files](https://cucumber.io/docs/gherkin/reference).
- TDD (Test-Driven Development): 
  Tests are written before any app code.

## Prerequisites

- [Node.js](https://nodejs.org/).
- [Bun](https://bun.com/).
